= Podman Desktop Extension for Physical AI Robotics Development
:icons: font

== Overview

This repository contains a Podman Desktop extension that gives robotics developers a GUI-driven path from local development to OpenShift deployment.

*Target audience:* Robotics engineers unfamiliar with containers, CLI, or enterprise Linux.

*MVP target:* ROSCon Toronto demo, September 2026.

For features, screenshots, and end-user quick start, see link:physical-ai/packages/backend/README.md[packages/backend/README.md] (ships in the published extension image).
