== Overview

A Podman Desktop extension that gives robotics developers a GUI-driven path from local development to OpenShift deployment.

*Target audience:* Robotics engineers unfamiliar with containers, CLI, or enterprise Linux.

*MVP target:* ROSCon Toronto demo, September 2026.

=== What It Does

* Curated catalog of ROS2 base images (Ubuntu interim) pullable from Quay.io
* Image Builder with two-phase build (base + simulation) and Quick Start presets
* One-click launch of ROS2 + Gazebo simulation in a single Podman container
* Browser-based simulation visualization via noVNC
* Add TurtleBot3 robots into a running simulation interactively
* ROS2 topic inspection panel _(planned — APPENG-5773)_
* Multi-robot local fleet scaling with Zenoh middleware _(stretch)_
* Export to Kubernetes manifests and deploy to OpenShift _(stretch)_

=== Strategic Drivers

* Push workloads to OpenShift and the Red Hat ecosystem
* Clear path from Ubuntu builds on laptops to Fedora (and eventually RHEL) containers
* Bridge the gap from robotics lab projects to hardened, full-scale production deployment on OpenShift

== Quick Start

=== Prerequisites

* https://podman-desktop.io/[Podman Desktop] >= 1.28.0
* Podman >= 5.x (tested with 5.8.5)
* Node.js >= 24.0.0, npm >= 11.0.0 (matches Podman Desktop's own Node requirement)

==== Podman Machine Requirements

[cols="1,1,1,2"]
|===
| Resource | Minimum | Recommended | Notes

| CPUs | 4 | 6+ | Gazebo + Nav2 + noVNC are CPU-bound under software rendering
| Memory | 4 GB | 8 GB | Single sim container uses ~2.5–3 GB. Default ~5.7 GB works for 1–2 robots. Increase for 3+ robots.
| Disk | 30 GB | 50+ GB | Base image ~1.5 GB, sim image ~3 GB, plus build cache layers
|===

To adjust: `podman machine set --memory 8192 --cpus 6` or use *Settings → Resources → Podman Machine* in Podman Desktop.

NOTE: On Mac Apple Silicon, Podman uses LibKrun (no GPU passthrough). Simulation runs with software rendering (llvmpipe). This is sufficient for demo purposes.

=== Build

[source,bash]
----
cd physical-ai
npm install
npm run build
----

=== Load in Podman Desktop

. Enable **Development Mode**: *Settings > Preferences > Extensions > Development Mode*
+
image::docs/images/enable-dev-mode.png[Enable Development Mode,600]
. Navigate to *Extensions* in the left nav
. Go to the *Local extension* tab
. Click "Add a local folder..." and select `packages/backend`
. The "Physical AI" extension appears in the navbar
+
image::docs/images/physical-ai-extension.png[Physical AI Extension,600]
